# Boo-Ville: The Silly Spooky Night!

An interactive, kid-friendly Halloween courtyard world built for children under 10 (ages 4–9) and hosted on GitHub Pages.

- **Play Live:** https://lucmanaly.github.io/Halloween/ *(once deployed)*
- **Master Plan & Architecture:** [`PLAN.md`](./PLAN.md)
- **Live Progress & LLM Handoff:** [`PROGRESS.md`](./PROGRESS.md)

## Features (Phase 1)
- Animated twilight Halloween courtyard with glowing pumpkins, haunted manor, musical fence, bubbling cauldron, whispering tree, and friendly spider.
- 60fps Canvas effects: fireflies, drifting autumn leaves, poppable rainbow bubbles, shooting stars, and sparkle confetti bursts.
- 10 discoverable courtyard secrets with playful Web Audio sound effects and gentle background music.
- Autonomous surprise events every ~20 seconds (Bubble Storm, Runaway Candy Cart, Shooting Star Shower, Playful Bat Flock).
- Kid-safe controls: audio mute, music & SFX volume sliders, reduced motion mode, Easy/Playful age mode, and 2-step reset protection.

## Local Development

```bash
npm install

```

